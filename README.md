# .github

This repository holds what github.com/rotascale shows at the top of its page:
[`profile/README.md`](profile/README.md), and the two logo files beside it.

It holds no code. The products are described at [rotascale.com](https://rotascale.com), and
what is open is in [agent-governance-spec](https://github.com/rotascale/agent-governance-spec)
and [rotascale-sdks](https://github.com/rotascale/rotascale-sdks).

The Rotascale name and the kingfisher are not covered by an open-source licence. How to use
them is at [rotascale.com/branding](https://rotascale.com/branding/).
